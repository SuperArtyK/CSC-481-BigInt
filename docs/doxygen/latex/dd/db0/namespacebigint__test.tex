\doxysubsection{Detailed Description}
Test support utilities for validating \doxylink{classBigInt}{Big\+Int} internals and copy/\+move semantics. 

This namespace contains helpers used by unit tests to inspect private representation details, assert expected storage layouts, and confirm that assignment operations preserve the value without changing internal sign or limb ordering.
