Detailed Description

Big integer type class, copies the functionality of regular integers, but on arbitrary scale.

Note
Technical limit for the size of the BigInt is std::size_t*digits(limb_t)

◆ normalise()

void BigInt::normalise ( )

Removes the most significant 0-limbs of the number, and removes negativity if number evaluates to 0.

Note
Helps to remove confusion from algorithms that expect the most significant limb to be non-zero.
Remember to run this after each non-normalising operation that reduces the bigint size.
