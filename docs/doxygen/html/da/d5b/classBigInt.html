Detailed Description

Big integer type class, copies the functionality of regular integers, but on arbitrary scale.

Note
Technical limit for the size of the BigInt is std::size_t*digits(limb_t)

Converts the BigInt to scientific notation.

Precondition

Parameters
maxSigDigMaximum number of significant digits; must be positive.
padIf true, pads the mantissa to exactly maxSigDig digits.
Returns

Note
