Detailed Description

Big integer type class, copies the functionality of regular integers, but on arbitrary scale.

Note
Technical limit for the size of the BigInt is std::size_t*digits(limb_t)

◆ normalise()

void BigInt::normalise ( )

Removes the most significant 0-limbs of the number, and removes negativity if number evaluates to 0.

Note
Helps to remove confusion from algorithms that expect the most significant limb to be non-zero.
Remember to run this after each non-normalising operation that reduces the bigint size.

Sets a magnitude limb and normalizes the result.

Parameters
indexZero-based limb index, least significant first.
valueNew limb value.
Returns
True on success; false if the value exceeds STORAGE_MAX, without modifying the object.
Note
An out-of-range zero write is a successful no-op, without resizing or normalization.
Successful writes preserve the sign unless the resulting magnitude is zero.
Warning
Storage allocation and capacity failures may throw exceptions.

bool BigInt::setLimbRaw ( const std::size_t index,
const limb_t value )

Sets a magnitude limb without normalizing the representation.

Parameters
indexZero-based limb index, least significant first.
valueNew limb value.
Returns
True on success; false if the value exceeds STORAGE_MAX, without modifying the object.
Note
Out-of-range writes extend storage with zero-filled limbs, even when value is zero.
Attention
The resulting representation may require normalization before numerical operations.
Warning
